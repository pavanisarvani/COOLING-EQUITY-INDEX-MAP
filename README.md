# COOLING-EQUITY-INDEX-MAP OF VISAKHAPATNAM AREA 
The Cooling Equity Index Map is an analytical spatial tool designed to evaluate and visualize urban heat stress alongside socio-economic vulnerability. By integrating satellite-derived land surface temperatures, green cover data, and population demographics, this map identifies heat-vulnerable neighborhoods that lack adequate cooling infrastructure. The tool provides an evidence-based foundation for urban planners, policymakers, and communities to prioritize climate-resilient interventions, such as strategic tree planting and cooling center placement
